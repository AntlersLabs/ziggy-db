Secure, read-only production database pulls for local development with industry-standard guardrails.

## Installation

You can install the package via Composer:

```bash
composer require antlerslabs/ziggy-db
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="ziggy-db"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="ziggy-db-config"
```
